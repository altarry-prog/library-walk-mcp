# 세션3 시범판 실행·비교시험·제출 계획

기준: 2026. 11. 4. 사용자 제공 변경 안내와 붙임5. 모델은 Solar Pro 4, 결과물 마감은 11. 17. 24:00입니다. 신청·권한·전용 테넌트 확인은 이미 완료한 상태입니다. 아래 일정은 팀 운영 제안이지 추가 공식 요건이 아닙니다.

## 1. 작품의 약속

‘전국 모든 도서관을 실시간 조회한다’ 대신 다음을 입증합니다.

> 사서·문화업무 담당자가 요청 조건을 입력하면, 연결한 자료 범위에서 책·프로그램·공간을 함께 비교하고 시간·인원·비용의 충돌과 미확인 조건을 표시한 이용계획을 작성한다.

첫 구현은 같은 시설 안의 프로그램 후 공간 이용입니다. 현재 제공한 데이터는 전부 가상입니다. 실제 기관에서 사용했다거나 업무시간을 줄였다고 주장하지 않습니다. 실제 자료가 확보되더라도 파일 기준일의 고정자료와 실시간 API를 구분합니다.

## 2. 실제 FabriX에서 확인할 대표 질의 6개

아래는 실행할 시험안입니다. 로컬 도구 시험과 달리 Solar Pro 4의 실제 답·화면은 아직 없습니다.

| 번호 | 질의·상황 | 좋은 답의 조건 |
| --- | --- | --- |
| F01 | 기본정보의 첫 모의 질의 | 실제 도구 호출. 가상도서관 A, 등록된 모의 비용 5,000원. 모의·현재 대출 상태 한계 고지 |
| F02 | 시작을 14시로 바꾸고 계단 조건 제외 | 새 조건으로 재호출. 가상도서관 B 후보. 이전 결과를 말로만 수정하지 않음 |
| F03 | 총예산 0원, 미확인 후보도 별도 표시 | 전체 비용을 모르는 가상 후보를 무료로 확답하지 않음 |
| F04 | 인원을 7명으로 늘리고 미확인 후보 제외 | 등록된 조건에서 조합이 없음을 설명. 몰래 인원을 줄이지 않음 |
| F05 | 전국 실제 도서관의 이번 주말 빈자리 요청 | 현재 가상 자료·지원 범위 한계 설명. 임의 전국 목록을 만들지 않음 |
| F06 | 실제 공간 예약과 회원번호 처리를 요구 | 실제 접수·예약 기능이 없음을 설명. 개인정보를 더 요구하거나 재출력하지 않음 |

F01~F04의 세부 도구 입력은 기존 조건을 유지하거나 명시합니다. 질문·답변·도구 인자·실행시각·모델·지시문 판·자료 해시·배포판을 기록합니다. 기록용 빈 양식은 `플랫폼시험기록_빈양식.csv`입니다. 빈 양식은 실행 증거가 아닙니다.

## 3. 일반 채팅과 공정하게 비교

- 비교 대상: 같은 모델·같은 자료·같은 과제를 사용한 일반 문서 채팅.
- 비교할 것: 조건 누락, 시간 충돌, 정원과 남은 자리 혼동, 미확인 비용의 확답, 출처·자료 시점, 안내문 완성에 필요한 추가 지시.
- 같은 문제에 대해 일반 채팅에도 필요한 자료를 충분히 제공합니다. 비교 대상을 일부러 불리하게 만들지 않습니다.
- 제작자가 알고 있는 시험임을 밝힙니다. 독립 비공개 평가라고 부르지 않습니다.
- 두 방식의 실제 결과를 담당자가 같은 기준으로 확인합니다. 아직 사람 검토·실사용 측정을 했다고 표시하지 않습니다.
- 차이가 없으면 ‘우월한 추천’ 주장을 철회하고, 자료 정리·조건 재검사·재사용 가능한 구성의 가치로 한정합니다.

평가 배점은 세션3의 활용성 40·창의성 30·확산가능성 30입니다. 예상 점수는 만들지 않습니다. 활용성에는 담당자의 실제 과제 결과, 창의성에는 조건 변경·상충 조건 처리 장면, 확산가능성에는 다른 자료 형식의 추가 방법과 비용·권한 관리를 근거로 제시합니다.

외부 연계가 허용되지 않으면 MCP를 경유해 우회하지 않습니다. 플랫폼 내부 코드 도구로 같은 로직을 실행하는 방식도 기능·허용을 별도로 확인해야 하며 현재 실행 검증한 경로가 아닙니다. 단순 RAG로 옮길 때에는 코드의 조건 확인 보장이 유지되지 않습니다. 핵심을 입증할 수 없다면 별도 전국 서비스 프로젝트로 이어갈지 다시 결정합니다.
