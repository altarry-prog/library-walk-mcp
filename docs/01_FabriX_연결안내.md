# FabriX 연결 안내: 적용 준비판

**확인 범위:** 서버의 로컬 MCP 통신은 시험했습니다. 실제 FabriX 테넌트의 등록 화면·권한·외부 접속·모델 도구 사용은 아직 시험하지 않았습니다. 아래는 확인된 개발 안내와 이 서버의 실제 구현을 맞춘 적용 절차입니다.

## 1. 연결 전에 확인할 두 가지

1. 세션3와 기관에서 ‘전용 FabriX Agent가 외부 MCP로 공개 자료를 읽어 상담·문서를 만드는 방식’을 허용하는가.
2. 테넌트가 외부 MCP의 Streamable HTTP 또는 SSE와 정적 Bearer 헤더를 지원하는가.

제품 소개에 MCP가 있다는 것과 대회 허용은 다릅니다. 정적 Bearer 방식은 OAuth가 아닙니다. OAuth만 지원하면 이 서버를 그대로 등록했다고 볼 수 없으며 인증 계층을 추가 검토해야 합니다. 인증을 없애서 우회하지 않습니다.

## 2. 서버 배포 준비

### 환경변수

| 이름 | 설정 | 주의 |
| --- | --- | --- |
| `MCP_ACCESS_TOKEN` | 운영자가 비밀값 관리 기능에서 만든 긴 임의 값 | 실제 값을 파일·채팅·Agent 지시문에 넣지 않음 |
| `PUBLIC_HOST` | 본인 소유의 승인된 공개 호스트 이름 | 프로토콜·경로 없이 입력. 임의 주소를 실제 배포 주소처럼 쓰지 않음 |
| `MCP_TRANSPORT` | 기본 `streamable-http`, 필요하면 `sse` | 서버와 FabriX 선택을 맞춤 |
| `MCP_ALLOWED_HOSTS` | 승인된 Host 값 | 로컬 기본값만으로 공개 주소를 허용하지 않음. 전체 `*` 금지 |
| `MCP_ALLOWED_ORIGINS` | 실제 요청에 Origin이 있을 때 관리자가 확인한 값 | 임의 와일드카드로 풀지 않음 |
| `CATALOG_PATH` | 기본 `data/demo_catalog.json` | data 폴더 밖 접근 차단 |
| `ALLOW_LIVE_CALLS` | 기본 `false` 유지 | 실자료·승인·한도 확인 전 켜지 않음 |
| `EXTERNAL_LINK_APPROVED` | 기본 `false` 유지 | 켜는 행위가 실제 승인 자체는 아님 |
| `NARU_KEY` | 실자료 시험이 승인된 경우 서버 환경변수에만 설정 | 기존 세션1 키·한도를 임의 재사용하지 않음 |

### Docker·HTTPS 적용 순서

Docker가 있는 운영자 소유 서버용 구성입니다. 이 환경에서는 Docker가 없어 아래 배포 명령을 실행하지 않았습니다.

1. 소유·승인된 도메인의 DNS를 해당 서버에 연결합니다. 기존 책이지 서버는 사용하거나 바꾸지 않습니다.
2. `.env.example`을 `.env`로 복사하고 **비밀이 아닌 값만** 채웁니다. `PUBLIC_HOST`가 대표적인 필수 값입니다.
3. 인증값은 호스트 환경변수 또는 배포 플랫폼의 비밀값 기능에 별도로 설정합니다. `.env`에 적지 않습니다.
4. 서버 방화벽·기관 외부 접속 정책·인증서 발급 조건을 확인합니다. 구성은 HTTPS 앞단을 통해서만 MCP에 접근하도록 되어 있습니다.
5. 패키지 폴더에서 구성 검사를 하고 실행합니다. `config --quiet`는 인증값이 포함된 전체 구성을 화면에 찍지 않기 위한 선택입니다.

```sh
docker compose config --quiet
docker compose up -d --build
```

Caddy가 공개 HTTPS 앞단을 맡고 Python 서버는 내부 컨테이너의 8000번 포트에서 실행됩니다. 인증서 발급·DNS·방화벽·호스팅 정책이 충족되어야 하므로 이 파일만으로 공개 주소가 자동 확보되지는 않습니다. 운영 로그·보관기간·접근권한은 별도 검토해야 합니다.

## 3. 서버 측 확인

- `/health`: 서비스와 모의 여부만 확인. 정보나루·모델 호출 없음.
- `/mcp`: Streamable HTTP MCP 주소. 단순한 REST 조회 주소가 아닙니다.
- `/sse`: `MCP_TRANSPORT=sse`로 실행한 경우의 MCP 연결 주소.
- 한 프로세스에서는 선택한 전송 방식 하나를 사용합니다. 두 주소가 동시에 켜진다고 가정하지 않습니다.

운영자가 관리하는 HTTPS 주소만 검사합니다. 인증값은 환경변수에서 읽습니다. 다음 주소는 자리표시자이며 실제 배포 주소가 아닙니다.

```sh
.venv/bin/python probe_mcp.py --url https://YOUR_APPROVED_HOST/mcp
```

SSE를 선택했다면:

```sh
.venv/bin/python probe_mcp.py --url https://YOUR_APPROVED_HOST/sse --transport sse
```

이 검사는 초기화·도구 목록·자료 상태까지만 확인합니다. 실제 도서 API·모델·예약을 호출하지 않습니다. **이 외부 HTTPS 검사는 아직 실행하지 않았습니다.**

## 4. FabriX의 MCP 연결 입력표

등록 화면의 정확한 메뉴 이름은 확인하지 못했습니다. 테넌트 관리자가 허용한 MCP/외부 도구 연결 기능에서 다음 값에 대응하는 항목을 찾습니다. 보이지 않으면 다른 칸에 억지로 붙이지 말고 관리자에게 지원 여부를 확인합니다.

| 항목 | 넣을 값 또는 판단 |
| --- | --- |
| 표시 이름 | `책이지 문화생활 읽기전용` |
| 서버 주소 | 승인된 실제 HTTPS 주소 + `/mcp`, 또는 SSE 구성의 `/sse` |
| 전송 방식 | 서버의 `MCP_TRANSPORT`와 동일 |
| 인증 | 정적 Bearer 또는 사용자 지정 Authorization 헤더를 지원할 때만 현재 구성 적용 |
| 헤더 이름 | `Authorization` |
| 헤더 값 | `Bearer {서버에 설정한 인증값}`. 여기의 중괄호는 자리표시자이며 실제 값이 아님 |
| 사용 범위 | 본인·시험 담당자·심사위원 등 필요한 최소 범위 |
| 조회할 도구 | 아래 6개가 실제 표시되는지 확인 |

인증값은 플랫폼의 보안 입력란에만 넣습니다. 일반 설명·지시문·Knowledge에 넣지 않습니다. UI의 자리표시자가 환경변수로 자동 치환된다고 가정하지 않습니다.

도구 목록:

```text
get_data_status
search_resources
make_visit_plan
search_books_live
find_holding_libraries_live
check_book_status_live
```

마지막 3개는 기본 비활성입니다. 가능하면 시범 Agent에는 앞의 3개만 연결하거나, 비활성 상태임을 확인해 둡니다. 실제 도구 입력 형식은 `mcp_tools_observed.json`에 기록했습니다.

## 5. Agent 작성

붙임5에서 확인한 지시문 작성 경로는 `AI Lab > Agent > Agent 생성 > Prompt > Simple Agent`와 역할 설정의 `Custom`입니다. **이 유형에서 MCP 도구까지 연결할 수 있는지는 별도로 확인해야 합니다.** 도구 연결이 안 보이면 테넌트에서 지원하는 도구 사용형 Agent 유형을 확인하고 같은 기본정보·지시문을 적용합니다.

1. 지정 모델 **Solar Pro 4**를 선택합니다. 이미지 생성 모델은 이 시범판에 필요하지 않습니다.
2. `02_Agent_기본정보.md`에서 이름·설명·예시 질문 4개·사용 방법을 옮깁니다.
3. 역할 설정에서 `Custom`을 선택하고 `03_Custom_지시문.txt` 본문을 넣습니다.
4. 승인된 MCP 연결을 도구로 추가합니다. 메뉴 노출만으로 연결 성공이라 하지 않습니다.
5. Knowledge는 필수가 아닙니다. 추가하더라도 승인된 공개 이용범위·용어 설명 정도만 사용하고 이 ZIP을 통째로 올리지 않습니다.
6. 시험 대화에서 실제 도구 실행 기록을 확인합니다. 도구 이름을 답변에 써 준 것만으로 호출 성공이라 하지 않습니다.

## 6. 처음 확인할 대화

- ‘현재 연결된 자료의 모의 여부와 범위를 도구로 확인해 줘.’
- 기본 모드라면 `DEMO`·가상 자료·외부 실호출 꺼짐을 설명해야 합니다.
- 이후 기본정보의 첫 예시 질문을 실행합니다. 도구 결과에 가상도서관 A, 모의 비용 5,000원이 나타나는지 비교합니다. 이 값은 가상 시험자료의 계산값이지 실제 이용료가 아닙니다.
- 미확인 후보를 허용한 질의에서 미확인 비용을 무료로, 희망 시간을 예약 가능 시간으로 바꾸지 않는지 확인합니다.

원본 저장·시험 완료·Store 배포·심사위원 열람은 각각 확인합니다. 원본을 바꾸면 배포판 재반영 여부도 확인합니다. 모든 사용자에게 공개하는 것이 대회 필수라고 확인된 것은 아닙니다.

## 7. 자주 생기는 실패

| 현상 | 확인할 것 |
| --- | --- |
| 연결 시간 초과 | 외부 통신 허용, DNS, TLS, 호스팅 기동 상태. 바로 정보나루 장애로 단정하지 않음 |
| 401 | 서버 환경변수와 FabriX 보안 헤더가 같은지, 인증 방식 지원 여부 |
| 421 | 승인된 Host/Origin 등록. 보호 기능을 끄지 않음 |
| 404·405·406 | 경로·전송 방식·MCP 클라이언트 지원. 일반 웹 주소 조회와 구분 |
| 413·429 | 요청 크기·빈도 제한. 인증키 교체로 우회하지 않음 |
| `disabled` | 실자료 도구가 안전하게 꺼진 상태. API 장애와 다름 |
| `source_unavailable` | 출처 일부를 확인하지 못함. 자료가 없다는 뜻이 아님 |
| 계획 후보 없음 | 범위·주제·시각·인원·예산·확인되지 않은 조건을 확인. 임의 시설을 만들어 넣지 않음 |

이 안내는 실제 플랫폼 적용·보안 승인·실사용 품질을 대신하지 않습니다.
