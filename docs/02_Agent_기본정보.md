# FabriX 기본정보: 모의 시범판

## 이름
책이지 문화생활

## 설명
사서·문화업무 담당자가 이용자의 취향과 시간·인원·예산·필요 시설 조건을 입력하면, 연결된 자료 범위에서 책·문화프로그램·공간을 함께 비교해 이용계획과 안내문을 만듭니다. 현재 기본 자료는 전부 가상입니다. 실제 신청·예약은 하지 않으며 부천시립도서관의 공식 서비스가 아닙니다.

## 모델·역할
- 모델: 전용 테넌트의 지정 모델 Solar Pro 4.
- 역할 지시문: `03_Custom_지시문.txt`.
- 실제 모델 선택·질답 시험은 사용자의 FabriX 환경에서 별도로 확인합니다.

## 예시 질문: 최대 4개

1. 모의자료로 2026년 11월 7일 13~17시, 우주를 좋아하는 가족 4명의 계획을 만들어 줘. 예산은 총 2만 원, 프로그램 후 공간 이용은 60분이야. 계단 없는 접근이 필요하고, 미확인 조건이 있는 후보는 빼 줘.
2. 모의자료로 같은 날짜 14~17시, 우주를 좋아하는 가족 4명의 계획을 만들어 줘. 총 2만 원 안에서 프로그램 후 공간을 60분 쓰고 싶어. 별도 시설 조건은 없고, 미확인 후보는 빼 줘.
3. 모의자료로 같은 날짜 13~17시, 우주를 좋아하는 가족 4명이 프로그램과 60분 공간 이용을 원해. 확인된 비용은 0원 이하여야 하고 계단 없는 접근이 필요해. 미확인 후보는 별도로 보여 주되, 무료나 예약 가능으로 확정하지 마.
4. 도구로 현재 자료의 모의 여부·지원 지역·자료 날짜를 확인하고, 전국 실시간 조회나 실제 예약이 가능한지 정확히 설명해 줘.

2·3번의 ‘같은 날짜’는 여기의 고정 시연 날짜인 2026. 11. 7.을 뜻합니다. 새로운 대화에서 의미가 불분명하면 날짜를 확인합니다. 실제 운영용 예시로 바꿀 때에는 승인된 자료에 맞게 날짜와 범위를 다시 작성합니다.

## 사용 방법

지역·날짜·시간대·취향·인원·예산·공간 이용시간·필요 시설 조건을 알려 주세요. 이름·회원번호·연락처·정확한 집 주소는 넣지 마세요. 모르는 조건은 먼저 확인합니다. 가상 자료의 결과는 실제 이용 가능한 장소나 프로그램이 아닙니다. 자료가 없거나 미확인인 부분은 그대로 남깁니다. 실제 신청과 예약은 공식 경로에서 사람이 확인합니다.

## 첫 시연의 기대값

첫 예시의 조건을 그대로 도구에 전달하면 가상도서관 A의 책·프로그램·공간 후보가 나옵니다. 모의 프로그램 13~14시, 모의 공간 희망 이용 14~15시, 등록된 모의 이용료 합계 5,000원입니다. 이는 로컬 도구 결과와 맞출 기준이며 **Solar Pro 4가 실제로 이렇게 답했다고 검증한 기록은 아닙니다.**
