# 자료 확보와 승인: 실제 연결 전 할 일

작성일 2026. 11. 4. 공개 설명 확인과 실제 API·자료 확보를 구분합니다. 문의 초안은 발송하지 않았습니다.

## 1. 자료별 현재 상태

| 자료 | 확인한 근거 | 구현 | 아직 필요한 것 |
| --- | --- | --- | --- |
| 정보나루 | 도서 검색·소장 도서관·하루 전 상태 API 설명 | 선택적 어댑터·모의 응답 시험 | 실제 이용권한·지역번호·응답·공동 한도 확인 |
| 부천 문화강좌 | 공식 CSV 열 8개, 연간 갱신 | CSV 변환기·가상 행 시험 | 실제 파일, 기관 연결, 실제 회차 시각·대상·비용 보완 |
| 전국 행사 | 행사 일시·장소·요금·연령·기준일 항목 | 현재 실시간 어댑터 없음 | 도서관 행사 포함 범위·신청 상태·권한·실제 응답 |
| 공유누리 | 강의실·강당·회의실·상세 자원 API 목록 | 현재 시간별 실시간 어댑터 없음 | 실제 요청 명세·승인·도서관 자원 포함·공개 가능 시간대 |

부천 문화강좌의 정원을 잔여석으로, 부천 GIS ‘공간정보’를 대관 현황으로 해석하지 않습니다. 공유누리의 ‘예약정보’라는 표현만으로 시간별 빈자리나 개인 예약정보 이용권한을 확보했다고 보지 않습니다.

## 2. 승인된 고정자료로 시작하는 방법

`data/approved_catalog.template.json`은 빈 양식입니다. 서버는 검토되지 않은 snapshot이나 빈 실제 자료 양식을 거절합니다.

1. 공개 자료의 출처·이용조건·기준일을 확인합니다.
2. 기관 이름을 공식 번호·공개 주소·공식 페이지와 대조해 공통 시설 ID로 연결합니다. `library_map.template.json`은 빈 양식입니다.
3. 부천 CSV를 받았다면 기존 파일을 보존하고 새 파일로 변환합니다. 아래의 파일명은 사용자가 준비한 승인된 파일의 예시입니다.

```sh
.venv/bin/python import_bucheon_csv.py data/approved_bucheon.csv --library-map data/library_map.json --basis-date 2026-09-09 --output data/bucheon_review_draft.json
```

이 명령의 실제 CSV 파일은 묶음에 없습니다. 기준일도 내려받은 실제 판에 맞춰야 합니다. 변환기는 주제·대상·기관 연결·시각을 임의로 채우지 않습니다. 변환 결과만으로 통합 계획이 완성되지 않습니다.

4. 실제 회차의 `date/start/end`, 등록 주제, 기관 연결, 알려진 요금·설비·시간대를 확인합니다. 모르는 항목은 null 또는 명시한 미확인 상태로 둡니다.
5. 같은 시설의 도서·프로그램·공간을 합쳐 검토합니다. source_status는 자료가 실제로 준비된 종류만 ok로 표시합니다.
6. 사람이 실제로 대조한 뒤에만 `human_reviewed=true`로 표시합니다. 이 표시도 기관 보안 승인이나 도입 승인 증명은 아닙니다.
7. 원본은 보존하고 새 자료 판·해시를 남깁니다. 승인되지 않은 자료를 가상 자료와 섞어 실제 서비스처럼 보여 주지 않습니다.

현재 `search_resources`와 `make_visit_plan`은 이 고정 카탈로그를 읽습니다. 정보나루 조회 결과가 자동으로 카탈로그에 적재되지는 않습니다. 전국 실자료 적재 전에는 전체 필드 검증·규모·갱신·기관 연결을 추가 검토해야 합니다.

## 3. 세션3 운영진 문의 초안

> 전용 FabriX의 Solar Pro 4 Agent가 외부 MCP 서버를 통해 공개 도서·행사·공간 정보를 읽기 전용으로 조회하고, 상담·이용계획 문서를 작성하는 방식의 출품을 검토하고 있습니다. 실제 예약·신청·회원정보·운영 시스템 연동은 하지 않습니다.
>
> ① 공개 안내의 외부 API·연계 제한 아래에서 이 방식이 허용되는지, ② 사전 승인 절차, ③ 허용 전송 방식과 인증 방식, ④ 외부 HTTPS 접속 조건, ⑤ 도구를 연결할 수 있는 Agent 유형, ⑥ 심사위원 실행·열람 조건을 확인 부탁드립니다.
>
> 외부 연결이 제한될 경우, 승인된 공개 고정자료와 플랫폼 내부 코드 도구로 조건을 대조하는 방식은 허용되는지도 문의드립니다. 일반 메뉴 노출만으로 허용된 것으로 해석하지 않겠습니다.

## 4. 자료 제공기관 문의 초안

### 문화프로그램

> 앞으로 진행될 프로그램의 실제 회차 날짜·시각·장소·대상·접수 기간·현재 접수 상태·공개 가능한 남은 자리를 제공하는 자료가 있는지 문의드립니다. 연간 운영 현황과 실시간 접수 상태를 구분하려고 합니다. 자동 조회·표시·재배포 조건, 인증·한도·갱신시각도 확인 부탁드립니다.

### 공간·공유누리

> 도서관 모임공간의 인원·설비·이용조건·요금과, 특정 날짜·시간대의 공개 가능한 이용 가능 상태를 읽기 전용으로 조회하려고 합니다. 개인 예약 내역은 필요하지 않습니다. API 목록의 예약정보가 집계·이용내역·공개 시간대 중 무엇인지, 상세 명세·승인·한도·재배포 조건을 확인 부탁드립니다. 실제 예약 생성은 이번 범위에서 제외합니다.

### 정보나루

> 기존 서비스와 호출 한도를 공동 사용하고 있어 별도 활용 범위·키 관리·캐시·허용 요청량을 확인한 뒤 제한된 시험을 하려 합니다. 일괄 전국 조회나 키 교체로 한도를 우회하지 않습니다. 참여기관 범위·지역번호·상태의 기준 시점도 확인하겠습니다.
