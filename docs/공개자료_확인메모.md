# 공개 자료 확인 메모

2026. 11. 4. 공식 설명·표를 읽은 기록입니다. 자료 API의 실제 응답을 조회한 기록은 아닙니다.

## 부천 문화강좌: 새로 찾은 실제 자료

- URL: https://www.data.go.kr/data/3075878/fileData.do
- 제목: 경기도 부천시_문화강좌_20260909.
- 관리 부서: 상동도서관. CSV 545행, 연간 갱신, 수정일 2026. 9. 9., 다음 등록 예정일 2027. 9. 30.으로 기재되어 있습니다.
- 공식 열: `강좌명`, `운영도서관`, `대상`, `신청기간시작일`, `신청기간종료일`, `교육시작일`, `교육종료일`, `정원`.
- 정확한 회차 시각·요일·남은 자리 열은 없습니다. 교육 시작·종료 날짜 사이를 매일 개최하는 일정으로 만들면 안 됩니다.
- 정원은 최대 모집 인원이지 남은 자리가 아닙니다.
- 페이지 미리보기에는 2026년 초 강좌가 있습니다. 이를 11월의 진행 예정 프로그램으로 사용하지 않았습니다.
- 파일 다운로드는 로그인 없이 가능하다고 안내되어 있습니다. 자동 변환 API는 회원 가입·활용신청이 필요합니다. 구체 API 주소는 아직 확보하지 못했습니다.
- 무료·이용허락범위 제한 없음으로 기재되어 있으나, 이것이 기관 보안 승인이나 대회 외부 연계 승인은 아닙니다.
- `import_bucheon_csv.py`는 이 열 구조를 기준으로 작성했고 가상 행으로 시험했습니다. 실제 파일 다운로드·정규화·기관 연결 검증은 아직 하지 않았습니다.

## 공간 자료

- 공유누리 일반 API 안내: https://www.eshare.go.kr/OpenApi/Info/index.do
- 실제 API 목록: https://www.eshare.go.kr/OpenApi/Info/list.do
- 안내에는 모임시설·문화시설 및 일별·월별 예약 관련 정보가 등장합니다.
- 실제 목록에서는 강의실·강당 목록, 회의실 목록, 상세 공유자원 정보 등을 확인했습니다.
- 시간별 빈 공간을 반환하는 실제 요청 주소·응답 항목·신청 권한은 아직 확인하지 못했습니다. 예약정보라는 이름만으로 빈자리 API라고 확정하지 않습니다.
- 부천 ‘공간정보 목록’은 GIS 자료 목록이며 공간 대관 가능 시간 데이터가 아닙니다. 이번 검색에서 부천 도서관 공간의 실시간 빈자리 API는 찾지 못했습니다. 존재하지 않는다고 단정한 것은 아닙니다.

## 전국 행사 자료

- https://www.data.go.kr/data/15013106/standard.do
- 전국공연행사정보표준데이터. 일시·장소·요금·입장연령·예매정보·기준일 등을 확인했습니다.
- `seatNumber`는 객석수이며 남은 자리가 아닙니다.
- 전국 모든 도서관 프로그램을 포괄한다는 근거는 없습니다.
- 이번 중간 코드에는 이 API의 실시간 어댑터를 구현하지 않았습니다.

## 정보나루

- API 설명: https://data4library.kr/apiUtilization
- 하루 전 기준 안내: https://data4library.kr/noticeV?cn=129
- 서지 검색 `srchBooks`, 소장관 조회 `libSrchByBook`, 소장·대출상태 `bookExist` 기반의 선택적 어댑터 코드를 작성했습니다.
- 실제 API는 호출하지 않았습니다. 응답 처리 시험은 모의 응답이므로 실제 제공기관과의 호환성 검증 완료가 아닙니다.
- 상세 지역번호는 임의로 넣지 않았습니다. 실제 연결 전에 공식 번호·기관 연결표를 확인해야 합니다.

## FabriX 연결

- 제품 설명: https://www.samsungsds.com/kr/ai-fabrix/fabrix.html
- MCP Server를 제공하는 외부 데이터·시스템 연결을 일반 기능으로 확인했습니다.
- ‘FabriX OpenAPI Connector’는 외부 시스템에서 FabriX 기능을 호출하는 설명도 포함합니다. 우리 MCP 서버를 Agent에 등록하는 방향과 혼동하지 않습니다.
- 상세 MCP 사용자 매뉴얼은 가져오지 못했습니다. 실제 경진대회 테넌트의 전송 방식·인증 방식·헤더 입력·공유 권한은 아직 확인하지 못했습니다.
- 작성한 서버는 로컬에서 Streamable HTTP(`/mcp`)와 SSE(`/sse`)를 각각 시험했습니다. 실제 FabriX 호환성이 검증됐다는 뜻은 아닙니다.
- 현재 서버 인증은 정적 Bearer 방식이며 OAuth 서버 구현이 아닙니다. FabriX가 OAuth만 허용하는 경우 추가 작업이 필요합니다. 무인증으로 바꿔 우회하면 안 됩니다.
