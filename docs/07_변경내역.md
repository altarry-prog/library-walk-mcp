# 0.2 변경내역과 남은 실제 적용

작성: Timely, 2026. 11. 4. 사용자의 ‘시범판과 전국 설계 둘 다, FabriX의 서버·커넥터·지시문까지 준비’ 요청에 따른 별도 로컬 작업입니다. 참조 저장소는 main `bb4da9b`(11. 4. 17:11 커밋)이며 원격 수정은 하지 않았습니다.

## 변경 목적

이전 중간본을 재개해, 실제 서버 도구 형식과 맞는 FabriX 적용 문서·지시문 및 전국 확장 설계를 완성하고 현재 코드판의 시험을 기록합니다. 새 실제 기관 서비스나 전국 데이터 확보를 완료했다고 주장하지 않습니다.

## 변경한 것

- 서버는 인증정보를 운영체제 환경변수로만 읽도록 정리했습니다. 인증값을 파일에 저장하거나 채팅으로 받을 필요가 없습니다.
- 선택적 정보나루 인증변수는 `NARU_KEY`입니다. 이전 중간 코드의 변수명과 다르므로 새 문서를 기준으로 합니다. 키는 실제로 설정하거나 사용하지 않았습니다.
- 자료 상태 도구에 서버의 KST 시각을 추가했습니다. 자료 기준일과 구분합니다.
- 시간대 파일이 없는 실행 환경에 대비해 `tzdata` 의존성을 추가하고 검사를 작성했습니다.
- 승인된 HTTPS 주소의 초기화·도구 목록·자료 상태만 검사하는 `probe_mcp.py`를 추가했습니다. 실제 외부 HTTPS 주소로 실행하지 않았습니다.
- 인증값·자료 경로·모의/실제 혼합·Host·요청량·자료 검토·시간대에 대한 구성 시험을 추가했습니다.
- FabriX 연결 입력표, 기본정보, 예시 질문 4개, Custom 지시문, 대표 질의 6개와 제출 계획을 작성했습니다.
- 전국 확장 상세설계, 자료 확보표·문의 초안, 비활성 자료 양식·제공기관 상태표를 작성했습니다.

## 실제 검증 범위

최종 시험 건수·시각·해시는 `VERIFICATION.md`, `MANIFEST_0.2.json`, `docs/test_core_current.log`, `docs/server-verification.json`에 기록합니다. 단위 시험은 가상 자료·모의 응답, MCP 접속 시험은 로컬 루프백입니다. Solar Pro 4의 실제 질답 시험과 다릅니다.

공식 부천 자료의 열 구조는 읽었지만 실제 CSV 전체를 내려받아 검증하지 않았습니다. 정보나루·전국 행사·공유누리 데이터 API도 실호출하지 않았습니다. 프로그램·공간 실시간 어댑터는 현재 미구현입니다.
